# Zog

A visually stunning, performance-optimized custom Linux distribution based on Arch Linux, designed for the Lenovo ThinkPad L13.

## Features

- **Beautiful Desktop**: KDE Plasma 6 with modern glassmorphism, blur effects, rounded windows, and smooth animations
- **Alternative WM**: Hyprland available as a secondary Wayland session
- **Performance**: Optimized for fast boot (<12 seconds), low idle power draw, smooth 60 FPS desktop
- **Developer-Friendly**: Preinstalled with VS Code, Git, Docker, Neovim, terminal tools (Zsh, Starship, eza, fzf, etc.)
- **Media & Creativity**: Firefox, GIMP, LibreOffice, OBS Studio, VLC, Spotify
- **Gaming & Entertainment**: Steam, Discord support via Flatpak
- **Security**: Firewall enabled by default, Wayland, Flatpak sandboxing
- **Easy Installation**: Calamares installer with automatic EFI partitioning, user creation, timezone selection

## Quick Start

### Flash the ISO

1. Download the latest ISO from [GitHub Releases](https://github.com/faint-dev/os/releases)
2. Flash to USB using Balena Etcher or Ventoy
3. Boot from USB on your ThinkPad L13
4. Run the Calamares installer from the desktop

### Build Locally (Advanced)

**Prerequisites**: Docker + OrbStack (macOS) or native Linux environment with `mkarchiso`.

```bash
# Generate package lists and sync theming
make iso

# Or, manually:
./scripts/gen-packages.sh
./scripts/sync-theming.sh
mkarchiso -v -w work -o dist archiso
```

See [BUILDING.md](docs/BUILDING.md) for full instructions.
